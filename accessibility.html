Accessibility Statement

Our commitment to making Adaptly accessible to everyone

Our Commitment

Adaptly is committed to ensuring digital accessibility for people with disabilities. We are continually improving the user experience for everyone and applying the relevant accessibility standards to ensure we provide equal access to all users.

Conformance Status

The Web Content Accessibility Guidelines (WCAG) define requirements for designers and developers to improve accessibility for people with disabilities. It defines three levels of conformance: Level A, Level AA, and Level AAA.

Adaptly is partially conformant with WCAG 2.1 Level AA. Partially conformant means that some parts of the content do not fully conform to the accessibility standard.

Accessibility Features

We have implemented the following accessibility features:

  • Semantic HTML structure with proper heading hierarchy
  • Skip navigation links for keyboard users
  • ARIA labels and landmarks for screen readers
  • Visible focus indicators for keyboard navigation
  • Color contrast ratios meeting WCAG AA standards
  • Alternative text for images
  • Keyboard-accessible interactive elements
  • Focus trap management in modal dialogs
  • Support for reduced motion preferences
  • Responsive design that works at various zoom levels

Compatibility

This website is designed to be compatible with:

  • Recent versions of Chrome, Firefox, Safari, and Edge browsers
  • Screen readers including NVDA, JAWS, and VoiceOver
  • Keyboard-only navigation
  • Browser zoom up to 200%
  • Mobile devices and tablets

Technical Specifications

Accessibility of this website relies on the following technologies:

  • HTML5
  • CSS3
  • JavaScript
  • WAI-ARIA

Known Limitations

Despite our best efforts, some limitations may exist:

  • Third-party forms: Some embedded forms from third-party services (MailerLite) may have accessibility limitations outside our direct control. We are working with these providers to improve accessibility.
  • PDF documents: Some downloadable documents may not be fully accessible. Contact us if you need an accessible alternative.

Feedback

We welcome your feedback on the accessibility of Adaptly. Please let us know if you encounter accessibility barriers:

Email: accessibility@adaptlyhq.com

General inquiries: hello@adaptlyhq.com

Response time: We aim to respond to accessibility feedback within 5 business days.

Assessment Approach

Adaptly assessed the accessibility of this website using the following approaches:

  • Self-evaluation using WCAG 2.1 guidelines
  • Automated testing tools (Lighthouse, axe DevTools)
  • Manual keyboard navigation testing
  • Screen reader testing with VoiceOver and NVDA
